# Referencias y diseño de A

Guardar aquí moodboard, paleta, composiciones de escritorio/móvil y el boceto de una arena base. Incluir origen de cada referencia y una frase sobre su aporte. El brief de A contiene búsquedas y páginas oficiales.

Referencia recibida del equipo: [arena-sketch-v1.png](arena-sketch-v1.png), copia del archivo original sin editar. Distribución: centro, A norte, B este, C sur, D oeste y cuatro apariciones de esquina. Todavía no define posiciones finales, escudos ni obstáculos procedurales; ver [maps.md](../maps.md).

Archivos sugeridos: moodboard.md, palette.md, arena-layout.png, arena-notes.md, gameplay-desktop.png, gameplay-mobile.png y screens.png. Son nombres sugeridos: el equipo puede usar otros si quedan claros.

El mapa debe mostrar paredes fijas, cinco nodos, apariciones, escudos, rutas protegidas y grupos variables según [maps.md](../maps.md). B convierte ese diseño en una plantilla y variantes; A no necesita crear otro mapa ni programar el generador.

Los bocetos no son arte final obligatorio ni deben cambiar las reglas del juego sin coordinarlo. Evitar una exploración extensa: primera dirección revisable en una hora.
